# Lip2Song: Multilingual Audio Synthesis from Silent Music Videos

## Overview
Lip2Song is an AI-powered system that generates synchronized multilingual audio from silent singing videos using lip-reading, translation, and speech synthesis techniques.

## Features
- Lip-reading from silent videos
- Multilingual translation
- Speech synthesis
- Audio-video synchronization
- Deep learning based architecture

## Technologies Used
- Python
- PyTorch
- OpenCV
- FastAPI
- React.js
- Hugging Face

## Project Type
B.Tech Final Year Project (2025-2026)

## Applications
- Media Localization
- Accessibility Solutions
- Entertainment Industry
- AI Content Generation
